## 调研结果（证据在仓库内）

### 1. 中继架构
- 本仓库只有客户端：`packages/dsh_remote`（REST、配对、Noise IK、控制 WebSocket + WebRTC 数据面）与 `app/lib/remote/relay/`（App 封装）。服务器软件是上游 ds-harness-remote（liguobao，MIT）的 server 端，不在本仓库。
- 默认服务器 `https://dsh.r2049.cn` 硬编码于 5 处：`app/lib/state/hosts_state.dart:464`（`defaultRelayServer`）、`packages/dsh_remote/lib/src/server/server_api.dart:13`（`defaultRemoteServer`）、`app/lib/state/app_info.dart:41`（网页控制台入口 `/app`）、`app/lib/ui/remote/remote_screen.dart:49/414`、l10n `remoteRestoreServer` / `remoteWebConsoleProvider`。
- 客户端钉死 wire 契约：plugin 0.6.2 / ds-harness-remote commit 479b943（`tunnel_carrier.dart:619`），端点白名单覆盖 0.5.17–0.6.0。自托管 server 必须跑兼容版本，部署前对照上游核对。
- 数据面降级顺序 LAN/P2P → TURN → 纯 Relay（WebSocket 经 server 转发）；TURN 凭据由 server 实时下发（`GET /api/v1/turn/credentials`），App 无静态 TURN 配置；Noise 握手只在最终选定数据面之后开始。
- App 已支持自托管服务器切换（邮箱 + 密码登录，`RelayServerController`，hosts_state.dart:371），协议层无需改动。

### 2. 用户可见品牌痕迹
- App 名：`android:label="DSH Go"`（`app/android/app/src/main/AndroidManifest.xml:55`）。
- 包名：`applicationId = "io.github.ccch1mneyyy.dsh_app"`（`app/android/app/build.gradle.kts:46`），在系统设置中可见。
- 品牌图形与吉祥物：`app/assets/brand/`、`app/assets/pets/`（Deepy、鲸娘）、启动图标 mipmap。ASSETS.md 明确：名称、标识、吉祥物不在 AGPL 授权范围内，fork 再发布必须换自己的名称和素材——硬性要求。
- 界面文案：`app/lib/l10n/parts/*.arb` 中英文各几十处 "DSH Go"，改后跑 `python3 app/tool/l10n_merge.py`。
- dshtui.com 依赖的端点（均写死在代码）：更新 `go.dshtui.com` / `dl.dshtui.com` + GitHub Releases（`app/lib/update/update_config.dart:43/48`）、统计 `go.dshtui.com/api/usage/v1`（`app/lib/usage/usage_net.dart:21`）、论坛 `forum.dshtui.com`（`app/lib/forum/forum_config.dart:6`）、插件市场 `go.dshtui.com/market`（`app/lib/state/plugins/plugin_market.dart:193`）、托管分享 `go.dshtui.com/c/…`（`app/lib/share_hosted/hosted_config.dart:7`）、分享回放页生成 HTML 中的 GitHub release 链接（`app/lib/share_code/replay_viewer.g.dart:1220`）。

### 3. 平台现状
- Android：完整（Flutter 3.47 + Kotlin 原生层，arm64 真机 / x64 模拟器两种风味）。
- iOS：无代码。仓库无 `app/ios/`，README「尽快适配 iOS 和鸿蒙」是承诺未实现。纯 Dart 包（`dsh_client`、`dsh_remote`）可复用；Kotlin 原生运行时层（proot 解压、前台服务、无障碍/手机操控）在 iOS 上要另写。

### 4. 手机 web 连接
两条路，均不在本仓库实现：
1. 中继服务器的网页控制台 `dsh.r2049.cn/app`（ds-harness-remote server 自带的 web 端，App 内「网页版远程控制台」入口）。自托管 server 若带该 web 端，手机浏览器可直连。
2. 主机自身的 `dsh web`（暴露 token 地址，局域网或隧道），App 内 WebView 兜底走的就是这条路（本机 `127.0.0.1:3080/?token=…`）。
本仓库没有中继协议的浏览器客户端（`site/share` 只是分享回放查看器）。

## 决策
- 通道 A + 自托管 server（自己的域名）；只改默认服务器与标识，协议层不动。
- applicationId 换成自己的包名：无老用户，无覆盖安装约束。APK 装在手机；电脑只跑 DSH + ds-harness-remote 插件；服务器跑 ds-harness-remote server。三端各装各的。
- dshtui.com 依赖的功能（更新、统计、论坛、市场、托管分享）先隐藏入口、保留代码。
- `docs/fork/` 为二开文档统一目录，每轮一个日期文件。
